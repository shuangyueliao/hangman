# Word Gallows · Hangman Word Game

Free single-file HTML5 word game. Guess the hidden word letter by letter
before the chalk figure is finished — six wrong guesses and it's over.
400 words in three difficulties (4–5, 6–8, 9–12 letters) with category
hints and short definitions, hand-drawn chalkboard art, streak multiplier
(×1.5 at 3+ wins), best-run and longest-streak saving. One HTML file,
zero assets.

**Play:** https://shuangyueliao.github.io/hangman/

- On-screen keyboard for touch + physical A-Z keys, Enter to continue
- Procedural chalk drawing with stroke animation on a textured blackboard
- Procedural WebAudio sounds (correct note, buzz, win/lose jingles), mute toggle
- Score: chances left × 100 + word length × 20, ×1.5 when streak ≥ 3
